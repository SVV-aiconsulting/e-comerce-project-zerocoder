# Сайт (этап 2+)

Эта папка — заглушка для будущего адаптера сайта.

Сайт будет работать как **отдельный процесс/контейнер** и использовать общее backend-ядро.

Не дублируйте здесь бизнес-логику — используйте сервисы backend или REST API.

Для авторизации по номеру телефона и связки с существующими клиентами:

- вызывать `POST /api/identify-customer/` с `channel=website` и `external_user_id`;
- передавать подтвержденный номер телефона пользователя;
- использовать `customer_id` из ответа для всех дальнейших операций.
