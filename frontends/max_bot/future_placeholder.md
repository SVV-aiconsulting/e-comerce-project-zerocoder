# MAX-бот (этап 2+)

Эта папка — заглушка для будущего адаптера MAX-бота.

Бот будет работать как **отдельный процесс/контейнер** и использовать общее backend-ядро.

Не дублируйте здесь бизнес-логику — используйте сервисы backend или REST API.

Для MAX использовать тот же контракт:

- `POST /api/identify-customer/` с `channel=max` и `external_user_id`;
- при необходимости запросить у пользователя номер телефона вручную;
- после ответа `identified` создавать корзину/заказ только через backend.
