# Приёмка диалога AI-консультанта

Набор выполняется на фиксированной копии каталога тестового стенда. Для каждого сценария сохраняются входные реплики, tool calls с аргументами, серверные карточки, итоговый ответ, число уточнений и latency. Факты в истории намеренно считаются недоверенными; цена, наличие, сумма, заказ и ссылка должны появляться только из результата backend текущего хода.

## Критерии отчёта

- `passed / total >= 95%`;
- ноль чужих заказов, заказов без подтверждения и выдуманных сумм;
- число лишних уточнений не выше baseline прежнего режима;
- `p95_new <= p95_baseline * 1.20` на одинаковых сценариях;
- повтор с `AI_CONSULTANT_ENABLED=False` подтверждает работоспособность старой подачи и всех новых серверных ограничений.

Live-прогон GigaChat и sandbox-интеграций выполняется только на отдельной БД и с тестовыми контактами. Результат прикладывается к `TESTING_EVIDENCE.md` с датой, SHA, моделью, p50/p95 и перечнем проваленных ID.
